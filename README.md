# エコリング仕入れリサーチ（入札受付中 即決リサーチ）

エコリング（ecoauc.com）の **入札受付中（即決／buy-now）** の商品を会員アカウントで集め、
メルカリ相場と突き合わせて「狙い目」を見つけるためのツールです。

動かし方は2通りあります。

- **ローカル（各自のPC内・公開なし）** … `start.command`（Mac）/ `start.bat`（Windows）で
  `http://localhost:8781/` を開くだけ。自分のPC専用なので **ログイン画面は出ず、すぐ一覧が表示** されます。
- **共有（先生が公開）** … `start_share.command` で認証サーバー（`auth_server.py` :8782）を常時稼働させ、
  Tailscale Funnel で公開URLを発行。生徒は **各自のエコリング会員ログインで閲覧** します（会員でない人には見られません）。

> ※ Playwright不要。Python標準ライブラリだけで動きます（HTTPフォームログイン）。

---

## 使い方（初回）

### Macの場合
1. **`config.txt`** を開き、自分のエコリング会員のメールとパスワードを記入して保存
   ```
   email=あなたのメール
   password=あなたのパスワード
   ```
   ※このファイルはあなたのPC内だけ。外部には一切送信されません（権限も自動で600）。
2. **`setup.command`** をダブルクリック → 「✓ ログイン成功」と出ればOK
3. **`start.command`** をダブルクリック → ブラウザで一覧がそのまま開きます（`http://localhost:8781/`・ログイン画面なし）

### Windowsの場合
1. Python を入れる（https://www.python.org/ ・「Add Python to PATH」にチェック）
2. `config.txt` にメール・パスワードを記入
3. コマンドプロンプトでこのフォルダに移動し `python collector.py --setup`（ログイン確認）
4. **`start.bat`** をダブルクリック

---

## 2回目以降

- **`start.command`（Mac）/ `start.bat`（Windows）** をダブルクリックするだけ。
- ログインのセッションは保存され、切れたときだけ自動で再ログインします。
- 画面の「最新を取得」で再収集。30分ごとにも自動更新。

## キーワードの変え方

**`keywords.txt`** を開いて1行に1つ。保存後「最新を取得」で反映。

- **ティファニー各ライン**（オープンハート等）… 左の相場表・狙い目判定の主役。
- **他ブランド**（エルメス／シャネル等）… 入札受付中の在庫を一覧で眺めるため。**不要なら行頭に `#`** で無効化。

## 画面の見方

3カラム構成です。

- **左：メルカリ相場表** … Tiffany 中古相場の目安（ライン名で検索可）。
- **中：入札受付中の商品** … 即決一覧。キーワードチップ／タイトル内検索／開始価格の下限上限／並び替え（新着・安い・高い）。
  各カードに「狙い目シグナル」と **「この商品で利益計算」**（右の計算機に連動）、**「エコリングで見る・入札」** を表示。
- **右：エコリング手数料計算機** … 想定売価から、利益別の入札上限（税抜）を逆算。

---

## なぜ「公開」しないのか

エコリングは会員限定。スクレイプしたデータを誰でも見られる形で公開するのは適切でないため、
**各自のPC内だけで完結する**形にしています。これなら会員でない人にデータが渡ることはありません。

## うまくいかないとき

- **「✗ ログイン失敗」** … config.txt のメール/パスワードを確認。先にブラウザで普通にログインできるか確認を。
- **ログインはできたが商品を解析できない警告** … エコリングの一覧ページの作りに合わせた微調整が必要です。
  このとき `eco_buynow_sample.html`（実際の入札受付中一覧）が保存されるので、それを渡してもらえれば解析を合わせ込めます。
